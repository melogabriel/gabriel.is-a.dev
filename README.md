# Gabriel Melo - Data Analyst Portfolio

This repository contains the source code for my personal portfolio website, live at [gabriel.is-a.dev](https://gabriel.is-a.dev/).

This is a fully responsive, single-page website designed to showcase my projects, skills, and professional experience as a Data Analyst. It features a clean, modern design with an interactive particle background and a dark/light mode theme switcher.

## Features

* **Responsive Design:** Looks great on all devices, from mobile phones to desktops.

* **Interactive Background:** Built with `tsparticles` for a dynamic, animated background that reacts to the theme.

* **Dark/Light Mode:** A theme switcher that respects user's system preferences and saves their choice in `localStorage`.

* **Scroll Animations:** Subtle fade-in animations on content sections using `AOS (Animate On Scroll)`.

* **Dynamic Content:** JavaScript is used to set the current year in the footer.

* **Working Contact Form:** The contact form is powered by [Formspree](https://formspree.io/) for a serverless backend.

## Technologies Used

This website is built from the ground up using modern web technologies.

### Core Technologies

* **HTML5**

* **CSS3**

* **JavaScript (ES6+)**

### Frameworks & Libraries

* [**Bootstrap 5.3**](https://getbootstrap.com/)**:** Used as the core CSS framework for layout, components (navbar, cards, accordions), and the theme-switching system.

* [**Bootstrap Icons**](https://icons.getbootstrap.com/)**:** For all icons throughout the site.

* [**tsparticles**](https://particles.js.org/)**:** Powers the animated, theme-aware particle background in the header.

* [**AOS (Animate On Scroll)**](https://michalsnik.github.io/aos/)**:** Used for the fade-in animations as you scroll down the page.

### Tools & Services

* [**Google Tag Manager**](https://tagmanager.google.com/)**:** For analytics and website tracking.

* [**Formspree**](https://formspree.io/)**:** Provides the backend service for the "Contact Me" form.

* **GitHub Pages:** Used for hosting the live website.

## How to Use

To run this website locally, you can either:

1. Fork/clone the repository and open the `index.html` file directly in your browser.

2. Use a simple local server (like the "Live Server" extension in VSCode) to view the site.
   
```
# Clone the repository
git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)

# Navigate to the directory
cd your-repo-name

# Open index.html in your browser or serve it locally
```
